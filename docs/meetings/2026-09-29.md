### 1. 참조 코드 처리

참조 코드는 legacy/ 패키지로 격리한 후 구현 방향성에 대한 참조용으로 유지하며 실제 코드로 대체한다.
참조 코드는 프로젝트 코드 완성 시 일괄 삭제한다.

### 2. 인터페이스 세부 구조 변경

2차 회의에서 결정된 기준 인터페이스에서 일부 내용을 수정한다.

- GameState의 getBoard()의 주석에서 모호한 표현을 제거하고 반환하는 값의 의미를 고정

### 3. Jira 운영

Jira 이슈 등록 방식은 팀원 전원이 Jira에 익숙하지 않은 점을 고려하여 프로젝트 규칙으로 지정되지 않은 부분은 자율 운영으로 한다.
이슈를 하나씩 등록 후 작업, 한 번에 여러 이슈를 등록 후 작업하는 방식 모두 허용한다.

### 4. 1차 요구사항 구현 기한

1차 요구사항의 구현은 시험기간과 2차 요구사항의 제시 가능성을 고려하여 구현 기한을 회의일 기준으로 2주(~2026-10-13)로 설정한다.

### 5. Gradle 환경 재점검
